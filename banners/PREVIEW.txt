                          🚀 COMO USAR
═══════════════════════════════════════════════════════════════════════════════

1️⃣  SUBSTITUA SUA FOTO:
    • Os banners têm placeholders marcados como "SUA FOTO"
    • Use uma foto profissional 400x400px
    • Veja o README em banners/README.md para instruções detalhadas

2️⃣  CONVERTA PARA PNG (opcional):
    cd web3-security-automation/banners
    ./convert-to-png.sh

3️⃣  USE NO LINKEDIN:
    • Vá ao seu perfil
    • Clique no ícone de lápis no banner
    • Faça upload do arquivo
    • Ajuste o posicionamento
